PROJECT OVERVIEW:
This project shifts heart disease prediction from the cloud to the 
edge using an ESP32 microcontroller. A Logistic Regression model 
(81.97% accuracy on the UCI Heart Disease dataset) is converted to 
C++ via micromlgen for local bare-metal inference, while ThingSpeak 
is used solely for real-time telemetry visualization.
